# K1 Max configuration

Runtime configuration snapshot for Massimo's rooted Creality K1 Max.

This repository stores machine configuration, helper scripts, macro files, and operational notes.
It does not store firmware binaries, generated logs, caches, or build artifacts.

Related repositories:

- MicioMax-Klipper/klipper: Klipper host code and MDF/multiprobe helpers
- MicioMax-Klipper/k1-klipper-firmware: K1 MCU firmware sources
